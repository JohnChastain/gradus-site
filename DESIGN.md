# Gradus Website Design

## Direction

The site carries the native app's cream, ink, and deep-blue identity into a
quiet editorial support surface. It should feel useful and established rather
than promotional.

## Color

- Background: `#f7f0db`
- Paper: `#fcf7e8`
- Elevated: `#fffdf2`
- Ink: `#1a1f29`
- Muted ink: `#4e5867`
- Brand blue: `#1454a1`
- Pale blue: `#cfdfe8`
- Line: `#d6ccb3`
- Sage: `#298f78`

Dark mode follows the native app's adaptive palette.

## Typography

Use the system font stack for fast loading and familiar iOS rendering. Headings
use strong weight and restrained scale. Body copy remains between 17 and 19
pixels with a maximum line length of 70 characters.

## Layout

- Maximum site width: 1160 pixels.
- Maximum reading width: 760 pixels.
- Persistent but compact masthead.
- Full-width sections instead of decorative floating cards.
- Mobile navigation wraps without hiding legal or support links.

## Components

- Wordmark: app icon plus Gradus name.
- Primary action: solid blue link with white text.
- Secondary action: plain text link with directional arrow.
- Legal contents navigation: compact in-page anchors.
- Notice: full-border, pale-blue information panel.

## Motion

Use only a subtle icon entrance and link transitions. Disable nonessential
motion when `prefers-reduced-motion` is enabled.
